# **App Name**: Campus Connect

## Core Features:

- Directory Display: Display current teachers and students in a responsive layout.
- Alumni Registration Form: A form for alumni to register, collecting necessary details.
- Admin Content Management: Allow admin to upload new photos and teacher info through a simple admin interface.

## Style Guidelines:

- Primary color: School's official color (e.g., Blue #007bff).
- Secondary color: Light gray (#f8f9fa) for backgrounds.
- Accent: Green (#28a745) for success messages and interactive elements.
- Clean, modern layout with clear sections for teachers, students, and alumni form.
- Use simple, recognizable icons for navigation and categories.
- Subtle transitions and animations to enhance user experience.

## Original User Request:
create an responsive website for a school, where I can check current Teachers, students. Also create a form where this will allow old students to register. Admin can add new photo and new teachers as well as send notifications
